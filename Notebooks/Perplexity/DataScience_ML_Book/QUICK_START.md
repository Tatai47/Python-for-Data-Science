# Quick Start Guide

## Welcome to Your Complete Data Science & ML Book!

This book contains **155 Jupyter notebooks** organized into **31 chapters** across **5 major parts**.

## Getting Started in 3 Steps

### Step 1: Install Dependencies
```bash
cd DataScience_ML_Book
pip install -r requirements.txt
```

### Step 2: Choose Your Learning Path

#### Path A: Complete Beginner
Start from the beginning:
1. Part I → Chapter 1 (NumPy) → Notebook 01
2. Work through all notebooks sequentially
3. Complete exercises in each notebook

#### Path B: Focused Learning
Pick a specific topic:
- Need visualization skills? → Part I, Chapters 4-6
- Want to master ML? → Part II, Chapters 10-15
- Interested in Deep Learning? → Part IV, Chapters 21-26
- Building NLP applications? → Part V, Chapters 27-31

#### Path C: Quick Reference
Use as a reference:
- Open INDEX.md to find your topic
- Jump directly to the relevant chapter
- Run specific notebooks as needed

### Step 3: Start Learning
```bash
# Launch Jupyter Notebook
jupyter notebook

# Or Jupyter Lab (recommended)
jupyter lab
```

Navigate to any chapter folder and open the notebooks in order (01, 02, 03, etc.)
