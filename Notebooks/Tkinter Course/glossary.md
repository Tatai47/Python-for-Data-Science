# Glossary

- **Application service:** A function/class implementing a user-visible use case independently of widget layout.
- **BSON:** MongoDB’s binary-encoded document representation with types such as ObjectId, Date, and Decimal128.
- **Callback:** A callable invoked later in response to a user action or scheduled event.
- **Canonical schema:** The normalized column names, dtypes, and row grain expected by analysis services.
- **Data grain:** What one row represents, such as an order or an order line.
- **DataFrame:** pandas’ labeled two-dimensional tabular data structure.
- **Event loop:** The dispatcher that processes GUI input, redraws, and scheduled callbacks.
- **Geometry manager:** Tkinter mechanism (`pack`, `grid`, `place`) that controls widget layout.
- **KPI:** Key performance indicator with a documented definition, units, comparison, and scope.
- **Least privilege:** Give a database/user/application only the permissions required for its role.
- **Pagination:** Limiting a visible or retrieved result to a bounded page.
- **Repository/adapter:** Layer that translates a file or database source into the application’s stable data contract.
- **Tcl/Tk:** The scripting language/runtime and GUI toolkit behind Tkinter.
- **ttk:** Tkinter’s themed widget set.
- **Vectorization:** Applying operations across whole arrays/columns rather than an explicit Python-level loop per element.
- **Worker thread:** A thread used for blocking work so the Tk UI thread can keep processing events.
