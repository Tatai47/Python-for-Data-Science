# Portfolio Project Roadmap

## 1. Student performance report
**Skills:** CSV/Excel ingestion, Pandas cleaning, NumPy summaries, Seaborn comparisons, statistical interpretation.  
**Deliverables:** clean dataset, subject-level report, three charts, one-page findings note.

## 2. Retail sales analytics
**Skills:** JSON/CSV ingestion, MySQL/SQLAlchemy, joins, Pandas groupby/pivot, Matplotlib and Plotly.  
**Deliverables:** metric dictionary, SQL queries, regional/product performance report, interactive chart.

## 3. Data quality audit
**Skills:** schema validation, missingness, duplicate detection, type coercion, outlier review, profiling.  
**Deliverables:** validation report, exception log, cleaned data, repeatable quality checks.

## 4. Statistical investigation
**Skills:** SciPy tests, confidence intervals, Statsmodels regression, diagnostics.  
**Deliverables:** analysis plan, effect estimates, diagnostic plots, caveats, reproducible notebook.

## 5. Predictive modeling
**Skills:** Scikit-learn pipelines, preprocessing, cross-validation, metrics, leakage prevention.  
**Deliverables:** baseline, candidate model, evaluation table, model limitations and monitoring plan.

## 6. Business intelligence dashboard
**Skills:** Streamlit, Pandas, Plotly, SQLAlchemy, caching and secrets.  
**Deliverables:** app, README, reproducible environment, sample screenshots/export, security notes.

## 7. Integrated capstone
Combine all skills into one repository with reusable modules, a data dictionary, quality tests, exploratory analysis, statistical reasoning, model baseline, dashboard, and executive summary.
