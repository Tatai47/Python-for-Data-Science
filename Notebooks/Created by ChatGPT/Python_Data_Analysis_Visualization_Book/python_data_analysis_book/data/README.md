# Included synthetic datasets

All files are fictional, deterministic teaching data generated for this book.

| File | Grain | Description |
|---|---|---|
| `sales.csv` | One order | 240 synthetic orders with date, region, product, units, price, discount, revenue, cost, profit, and customer ID. |
| `orders.csv` | One order | A subset of order fields for database and join practice. |
| `customers.csv` | One customer | 15 fictional customers with city, signup date, and segment. |
| `students.csv` | One student | 20 fictional students with subject marks, total, and average. |
| `messy_sales.csv` | One order-like row | A deliberately imperfect sample with missing values, inconsistent text, and duplicate rows. |
| `weather.json` | One city/date observation | Small nested-friendly JSON example. |
| `sample_api_response.json` | API response | Example status/count/results object saved locally for offline API lessons. |
| `sample_page.html` | HTML page | Tiny local HTML page for parsing examples. |

`revenue` is a synthetic order amount after discount. `profit` is revenue minus synthetic cost. Values are for education only and do not represent real businesses or market prices.
