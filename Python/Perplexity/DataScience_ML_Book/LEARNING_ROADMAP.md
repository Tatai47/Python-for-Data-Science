# Learning Roadmap

## Skill Level Assessment

### Beginner (0-6 months experience)
Focus on: Part I (Data Science)
- Master NumPy and Pandas first
- Learn visualization with Matplotlib/Seaborn
- Understand basic ML with Scikit-Learn
- Build simple dashboards with Streamlit

### Intermediate (6 months - 2 years)
Focus on: Part II (ML) + Part III (AutoML)
- Deep dive into gradient boosting (LightGBM, XGBoost, CatBoost)
- Learn statistical modeling with Statsmodels
- Master hyperparameter optimization with Optuna
- Explore AutoML tools for efficiency

### Advanced (2+ years)
Focus on: Part IV (Deep Learning) + Part V (NLP)
- Build neural networks with TensorFlow/PyTorch
- Use FastAI for rapid prototyping
- Master NLP with spaCy and Transformers
- Build LLM applications with LangChain/LlamaIndex

## Career Path Recommendations

### Data Analyst
Priority order:
1. NumPy, Pandas (Chapters 1-2)
2. Matplotlib, Seaborn, Plotly (Chapters 4-6)
3. Scikit-Learn basics (Chapter 7)
4. Streamlit (Chapter 8)

### Machine Learning Engineer
Priority order:
1. All of Part I (strong foundation)
2. LightGBM, XGBoost, CatBoost (Chapters 10-12)
3. Optuna (Chapter 15)
4. PyCaret, H2O (Chapters 16-17)
5. TensorFlow or PyTorch (Chapters 21-22)

### Deep Learning Researcher
Priority order:
1. Strong mathematical foundation (NumPy Chapter 1)
2. PyTorch (Chapter 22)
3. PyTorch Lightning (Chapter 25)
4. JAX (Chapter 26)
5. FastAI (Chapter 23)

### NLP Engineer
Priority order:
1. All of Part I (data manipulation skills)
2. spaCy (Chapter 27)

4. LangChain (Chapter 29)
5. LlamaIndex (Chapter 30)

### MLOps Engineer
Priority order:
1. Scikit-Learn pipelines (Chapter 7)
