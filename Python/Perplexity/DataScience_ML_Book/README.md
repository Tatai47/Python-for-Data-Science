# Complete Guide to Data Science, Machine Learning, AutoML, Deep Learning, and NLP

## Book Structure

This comprehensive book covers the entire spectrum of modern data science and machine learning technologies.

### Part I: Data Science (Chapters 1-9)
- NumPy, Pandas, Polars
- Matplotlib, Seaborn, Plotly
- Scikit-Learn, Streamlit, Pydantic

### Part II: Machine Learning (Chapters 10-15)
- LightGBM, XGBoost, CatBoost
- Statsmodels, RAPIDS.AI, Optuna

### Part III: AutoML (Chapters 16-20)
- PyCaret, H2O, Auto-sklearn
- FLAML, AutoGluon

### Part IV: Deep Learning (Chapters 21-26)
- TensorFlow, PyTorch, FastAI
- Keras, PyTorch Lightning, JAX

### Part V: NLP (Chapters 27-31)
- spaCy, Hugging Face Transformers
- LangChain, LlamaIndex, ChromaDB

## How to Use

Each chapter contains multiple Jupyter notebooks (.ipynb files) covering specific topics with:
- Theoretical explanations
- Code examples
- Practical exercises
- Real-world applications

## Getting Started

1. Install required packages: `pip install -r requirements.txt`
2. Navigate to any chapter folder
3. Open and run the notebooks in order
