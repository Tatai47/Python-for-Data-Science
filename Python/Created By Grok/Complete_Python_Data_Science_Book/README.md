## How to Use This Book

1. Start at Chapter 01 and proceed in order.
2. Open each `.ipynb` file in Jupyter Lab, VS Code, Cursor, or Google Colab.
3. Run every cell (Shift + Enter).
4. Complete the **Business Challenge** in each chapter.
5. After Chapter 13 you will have solid Python skills and can move confidently into data analysis.
