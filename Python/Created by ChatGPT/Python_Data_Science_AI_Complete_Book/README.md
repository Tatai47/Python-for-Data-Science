# Python for MBA Data Analysts – Full Chapter-wise Course

A complete, practical Python course designed specifically for **MBA students and professionals** who want to become data analysts or use data-driven decision making in business.

## Course Philosophy
- Business-first examples (sales, finance, marketing, operations, HR, telecom)
- Minimal theory, maximum practical application
- Every concept ends with a mini business case or challenge
- Progressive difficulty – from absolute beginner to real analytical work
- Ready-to-run Jupyter notebooks (`.ipynb`)

## How to Use
1. Open the folders **in order**.
2. Open each `.ipynb` file in Jupyter Lab / VS Code / Google Colab / Cursor.
3. Run cells sequentially (Shift+Enter).
4. Complete the **Business Challenge** exercises at the end of most notebooks.
5. After finishing Chapters 1-12, tackle the two Capstone projects.

## Recommended Setup
- Python 3.10 or higher
- Jupyter Lab or VS Code with Python extension
- Required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn mysql-connector-python pymongo openpyxl scipy
```

## Learning Timeline (Suggested)
- **Weeks 1-2**: Chapters 1-6 (Python fundamentals)
- **Weeks 3-4**: Chapters 7-9 (NumPy → Pandas → Visualisation)
- **Week 5**: Chapter 10 (Statistics)
- **Week 6**: Chapter 11 (Machine Learning)
- **Week 7**: Chapter 12 (Databases)
- **Week 8**: Capstone projects

## What You Will Be Able to Do After This Course
- Clean and analyse sales, customer, and operational data
- Build KPI dashboards and insightful visualisations
- Perform customer segmentation (RFM / clustering)
- Build and evaluate simple predictive models (churn, sales forecast, etc.)
- Extract data from MySQL and MongoDB
- Communicate findings clearly to non-technical managers

Happy learning – turn data into business decisions!
